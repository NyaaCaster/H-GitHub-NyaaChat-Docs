# 引用朗读

「引用朗读」给消息里**引号包裹的台词**加一个 🔊 按钮：点一下，就用这个角色对应的音色把台词读出来。

## 它能做什么

- 自动识别消息里**成对的引号内容**：`“…”`、`‘…’`、`「…」`、`『…』`。
- 每段台词后面跟一个 **🔊 按钮**，点按即合成并播放。
- **按角色绑定音色**：不同角色可以有不同的声音，同一段对话里各说各话。
- 消息里若出现「人名: “台词”」这样的人名前缀，会按那个人名去匹配音色。

## 开启与设置

1. 点聊天区顶部工具栏的**拼图图标**，打开扩展面板。
2. 选中「引用朗读」，打开启用开关。
3. 在它的设置面板里，会列出**本段对话的参与者**，逐个为角色挑选音色（内置 14 个 Edge-TTS 音色）。
4. 每个音色都可以**试听**，选定即生效；配置随设置存档一起保存，刷新后仍在。

> 没有主动指定音色的角色，会使用默认音色。

## 🔊 点了没反应？

- **服务端未配置语音上游**时，点击会得到 **503**：按钮短暂显示 ❌，并在浏览器控制台留痕。这需要在部署侧配置语音接口地址，属于部署项而非扩展本身的问题。
- **只认半角冒号**：`她说：“…”` 这种不带人名前缀的写法，不会被当作内联人名；人名需要写成 `Alice: “…”`。
- **引号要成对且不混用**：`“…”` 与 `「…」` 各自成对；`“…」` 这类错配不会匹配。
- **加粗的人名不参与匹配**：`**Alice**: “…”` 里的 `Alice` 不会作为内联人名，播放时按消息发送者匹配音色。
- 单段台词有长度上限（约 1000 字符），正好也是服务端一次合成的上限。
