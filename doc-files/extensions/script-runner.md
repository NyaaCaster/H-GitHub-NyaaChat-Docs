# 脚本运行器

「脚本运行器」让**角色卡自带的 JS 脚本**在 NyaaChat 里执行。它是角色变量、状态栏这类"会动的卡面"能工作的前提 —— 卡片作者写的那部分逻辑，靠它跑起来。

## 它负责什么

- **执行角色卡自带的脚本**：卡片里附带的逻辑会被加载并按顺序运行。
- **维护角色变量**：对话中动态变化的数值（好感度、当前时间、所在场所、物品栏……）由脚本读写，并随对话保存。
- **让状态栏显示真实数值**：带状态栏的角色卡，回复下方那张卡片（学生证、状态面板之类）显示的是**实时数据**，不是卡片里写死的初值。
- **支持的脚本类型**：MVU、MVU_Zod，以及前端动态界面类脚本。
- **优先推荐使用群友开发的[「万象角色引擎」](https://gen.ericfu66.icu/)制作的MVU角色卡**
  - 致谢[「万象角色引擎」](https://gen.ericfu66.icu/)开发者[**《洋与火》**](https://github.com/wannianchihuo1)和 [**fu**](https://github.com/ericfu66)

## 开启方式

1. 点聊天区顶部工具栏的**拼图图标**，打开扩展面板。
2. 选中「脚本运行器」，打开启用开关。
3. 面板里还有一个「**已开启 / 已关闭**」开关，它控制的是：**插件启用、切换角色卡时，是否自动执行该卡里已启用的脚本**（执行顺序就是脚本库中的列表顺序）。

> 关掉「脚本运行器」后，变量既不会产生也不会更新，状态栏会停在初始值。

## 脚本库

面板里的「**脚本库**」按钮（按钮上会显示 `已启用数 / 总数`）是集中管理脚本的地方：

- **启用 / 停用**单个脚本
- **删除**脚本
- **拖动排序** —— 列表顺序即执行顺序
- **从角色卡或文件导入**脚本

## 初始化与输入锁定

脚本装配和变量初始化需要一点时间（取决于卡片脚本与世界书的数量）。

- 这段时间输入框会**暂时锁定**，并显示"正在初始化角色脚本…"。初始化完成后自动恢复。
- 这样是为了避免在初始化没走完时发送消息 —— 那会让变量初始化落在错误的状态上，之后整段对话的变量都不再更新。
- 初始化窗口有上限，不会无限期等下去；到点会自动放行。

## 出错怎么办

- 脚本执行出错**不会影响正常聊天**，也不会让页面白屏。
- 错误会记进扩展面板的**运行日志**，面板同时显示最近一次错误（脚本名 + 原因）。
- 排查时先看运行日志，再看是哪个脚本报错；单个脚本卡住不会一直阻塞，初始化窗口到点会自动放行。
