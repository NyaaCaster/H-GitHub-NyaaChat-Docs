# EJS模板

「EJS模板」用于支持**要求「提示词模板」扩展的酒馆（SillyTavern）角色卡**。

NyaaChat 只负责**运行**角色卡里已有的模板，**不提供** EJS 的编写与编辑功能。
- **优先推荐使用群友开发的[「万象角色引擎」](https://gen.ericfu66.icu/)制作的 EJS角色卡**
  - 致谢[「万象角色引擎」](https://gen.ericfu66.icu/)开发者[**《洋与火》**](https://github.com/wannianchihuo1)和 [**fu**](https://github.com/ericfu66)

## 开启方式

1. 点聊天区顶部工具栏的**拼图图标**，打开扩展面板。
2. 选中「EJS模板」，打开启用开关。

启用即可，**不需要任何额外配置或操作**。
