# 扩展

「扩展」是 NyaaChat 的可选功能入口。每个扩展都是一个独立的小功能，可以**单独启用、单独配置**，互不影响；启用状态与配置都集中在**扩展面板**里。

## 打开扩展面板

聊天区顶部工具栏上的**拼图图标**就是扩展入口（在 Bypass 火焰图标同一排）：

- 只要**有任意一个扩展处于启用状态**，这个按钮就会着色并轻微呼吸 —— 一眼就能看出"扩展正在生效"。
- 点击打开面板：里面是已安装的扩展列表，选中某个扩展即可启用它、调整它的设置。

## 和酒馆（SillyTavern）扩展的关系

> ⚠️ **NyaaChat 的扩展与酒馆扩展不通用。**

- 早期版本提供过一层「酒馆扩展兼容」，**v1.6.1 已移除**：原来装在 NyaaChat 里的酒馆扩展不再生效。
- 现在的扩展由 Nyaa 按 NyaaChat 自己的插件契约重新开发或移植，功能会按需逐步补齐。
- 因此**不要把酒馆的扩展文件拷进来** —— 没有装载通道，拷了也不会工作。

## 目前可用的扩展

| 扩展 | 一句话说明 |
| --- | --- |
| **脚本运行器** | 让角色卡自带的 JS 脚本跑起来 —— 角色变量与状态栏都靠它 |
| **引用朗读** | 给消息里引号包裹的台词加一个 🔊 按钮，按角色音色朗读 |
| **EJS模板** | 支持要求「提示词模板」的酒馆角色卡 —— 启用即可，无需额外操作 |

## 启用状态与设置会保存

- 扩展的启用状态与配置跟随**设置存档**一起保存，导出 / 导入 / 云端同步都会带上 —— 换设备不用重配。
- 关掉某个扩展只是**停用**：它此前产生的数据（例如角色变量）不会被删除，重新启用即继续使用。
