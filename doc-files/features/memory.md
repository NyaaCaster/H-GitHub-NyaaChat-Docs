# 持久记忆

NyaaChat 的**持久记忆**让 AI 记住对话里的长期信息：早期对话会被提炼成事实摘要归档，之后按需召回——既节省上下文，也让角色"记得"更久。

## 开启与关闭

在**用户账号面板**（顶部工具栏 🪪）中打开／关闭「持久化记忆」开关：

- **开启**：会提炼新的记忆，并在需要时检索召回已有记忆。
- **关闭**：不再提炼、也不再召回；**已归档的记忆不会被删除**，重新开启即可继续使用。
- ⚠️ 关闭期间，记忆分界线以上的内容**既不会发送给模型，也不会被召回** —— 已经归档的历史轮次不会重新加入发送内容。

## 它是怎么工作的

1. 当对话变长，NyaaChat 可以把**最早的一批消息**提炼成结构化的事实摘要（对话中的「整理早期对话记忆」操作）。
2. 归档后聊天区会留下一条**记忆分界线**：线以上的内容不再随每轮发送，而是在需要时被检索召回。
3. 记忆按**批次**保存；配额用满时需要先把已有批次**合并压缩**，才能存入新的结果。

## 与上下文上限的关系

记忆的触发判定依赖**当前模型的上下文上限**：

- 模型上限识别得越准，触发判断越可靠。可在「设置 → 对话模型供应商 → 健康测试」中查看每个模型的上下文长度与最大输出长度。
- 若某个模型的上限未被识别（会按兜底值估算），可以在供应商配置里**手动填写**该值。

## 配额

- 持久记忆有**批次数配额**。
- 配额已满且只剩一个批次时无法压缩，需要先删除不再需要的历史对话以释放配额。
