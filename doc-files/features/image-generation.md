# 生图（ComfyUI 与图片供应商）

NyaaChat 的「生成图片」由**生图模型供应商**提供：内置的 NyaaComfyUI 服务（自带多套工作流与风格），也支持你自己的 ComfyUI 服务，或任何 OpenAI 兼容的图片 API。

## 从哪里生图

- **入口**：每条 AI 回复下方的 🖼️ **生成图片** 按钮，会基于该条消息的内容生成图片。
- **需要登录**：未登录时点它会提示你先打开「用户账号」面板登录。
- **配置位置**：设置弹窗 → **生图模型供应商**。

## 三类供应商

| 类型 | 说明 |
|------|------|
| **NyaaComfyUI**（内置） | 开箱即用：选择**工作流**与**风格**即可出图。按**图包次数**计次；提供「连通性检查」（只探测服务是否连通，**不生图**） |
| **自定义 ComfyUI** | 填自己 ComfyUI 服务的地址，用自己部署的工作流出图，不消耗图包 |
| **QinyAPI / 自定义生图 API** | OpenAI 兼容的图片接口：填 API 地址与 Key，再从清单里启用模型 |

**图片尺寸**（OpenAI 兼容类供应商）：方形 `1024×1024`、竖屏 `1024×1536`、横屏 `1536×1024`。

## 工作流就是"生图模型"

在内置 ComfyUI 里，**每一套工作流都是一个可直接选用的生图模型**：

| 工作流 | 文件 |
|--------|------|
| **Anima2D** | `Anima-Nyaa.json` |
| **RM真人·柔美** | `RedMix-Nyaa.json` |
| **DB真人·节操** | `DarkBeastKrea2-Nyaa.json` |

- 弹窗里点开「**ComfyUI 工作流配置文档**」可以查看**只读**说明：工作流文件与所需模型文件的📥下载链接、以及它们在你 ComfyUI 里的放置路径。
- ⚠️ **自建 ComfyUI 时**：工作流必须**先在你的 ComfyUI 上成功运行并出过图**，NyaaChat 才能使用它。

## 风格

内置多套画风（`风格Nyaa01`、`风格4.5.1`～`风格4.5.6`、`风格3.0.1` 等），默认 **`风格4.5.2`**；在供应商设置里随时切换。

## 画图提示词由独立智能体生成

你只需要说出想要什么，**画图提示词由服务端的「提示词智能体」生成**：

- 智能体模型由服务端固定，前端不能切换，密钥也不会下发到浏览器。
- 智能体不可用时**逐级回退**：提示词智能体 → 你自己配置的对话模型 → 模板化构建器。所以你通常仍能出图，只是提示词质量可能下降。

## 计费与额度

- **NyaaComfyUI（内置）按次数消耗「NyaaComfyUI 图包」**：`5 猫粮 = +30 次`，无硬上限。
- 图包余量不足时会提示是否扩容；当前余量可在**用户账号面板**查看（`剩余 N 次`）。详见 [额度与扩容](../account/quota-expand)。
- **自建 ComfyUI 不消耗图包**（走你自己的服务器）。

## 生成过程与失败表现

- 生成期间气泡上会显示来自 ComfyUI 的**进度**。
- 你可以随时**停止**生成；停止后该条消息会标记为「**[已停止生成图片]**」。
- 失败时消息里会写明原因（`生图失败: …`）并给出提示，不会静默失败。
